# منظومة أوربكس للمحاسبة وإدارة المؤسسات | Orbix ERP Enterprise v2.5

نظام متكامل وشامل لإدارة موارد المؤسسات (ERP) والمحاسبة المالية ونقاط البيع السريعة (POS)، مبني بتقنيات الويب الحديثة وإطار عمل Electron للعمل المكتبي والسحابي.

---

## 🌟 أبرز مميزات النظام
1. **المالية والحسابات العامة:** دليل حسابات شجري، قيود يومية، مراكز تكلفة، ميزانيات تقديرية، تسويات بنكية، حافظة شيكات، وإقفال فترات مالية.
2. **المبيعات ونقاط البيع السريعة (POS):** فواتير بيع، عروض أسعار، أوامر بيع، مرتجعات، طباعة إيصالات حرارية صامتة (Thermal 80mm)، فتح درج النقدية تلقائياً، والباركود وقراءة الميزان الإلكتروني.
3. **الفاتورة الإلكترونية والـ QR:** توليد رمز استجابة سريعة متوافق مع هيئة الزكاة والضريبة والجمارك (ZATCA/ETA) بتشفير TLV Base64 الحقيقي.
4. **المشتريات والموردين:** فواتير شراء، أوامر توريد، مرتجعات مشتريات، وحسابات الموردين.
5. **إدارة المخازن والمستودعات:** جرد آلي، تنبيهات حد الطلب، حركات مخزنية، تسعير ومجموعات أصناف.
6. **إدارة علاقات العملاء (CRM):** متابعة التحصيل، أعمار الديون، تصنيفات العملاء، ومشاركة الفواتير وكشوف الحساب مباشرة عبر **واتساب (WhatsApp)**.
7. **الموارد البشرية والرواتب (HR):** إدارة الموظفين، مسيرات الرواتب، السلف، والحوافز والخصومات.
8. **المستشار المالي الذكي (Orbix AI):** تحليل ذكي فوري للمبيعات، النواقص، هوامش الربح، والتحصيل مدعوم بمحرك ذكاء اصطناعي محلي مع دعم Google Gemini API.
9. **قاعدة بيانات PostgreSQL محلية وسحابية:** دعم التخزين المحلي فائق السرعة مع المزامنة التلقائية والاتصال بقواعد بيانات PostgreSQL وGoogle Cloud SQL.

## 🚀 طرق التشغيل المباشرة (على سطح المكتب)

### 1. تشغيل نسخة سطح المكتب (Desktop App):
- اضغط مرتين على ملف: **`2-Start-Desktop.bat`** أو الأيقونة المنشأة على سطح المكتب.
- سيقوم تلقائياً بتشغيل خادم PostgreSQL المحلي وقاعدة بيانات `orbix_erp` وفتح نافذة البرنامج المستقلة.

### 2. تشغيل عبر المتصفح (Web Edition):
- اضغط مرتين على ملف: **`1-Start-Web.bat`**.
- سيفتح النظام مباشرة على الرابط: `http://localhost:3000`.

### 3. إعداد وتهيئة قاعدة البيانات (Database Setup):
- اضغط مرتين على ملف: **`Setup-PostgreSQL-Database.bat`**.
- يقوم بالتحقق من خادم PostgreSQL المحلي أو الخارجي، وإنشاء الجداول العشرة الرسمية تلقائياً.

### 4. استخراج مثبت الويندوز المستقل (.EXE):
- اضغط مرتين على ملف: **`3-Build-Installer-EXE.bat`**.
- سيقوم ببناء ملف التثبيت التلقائي `Orbix ERP Enterprise Setup.exe` في مجلد `dist-electron`.

## ⚙️ متطلبات التشغيل
- نظام التشغيل: Windows 10 / 11 (64-bit)
